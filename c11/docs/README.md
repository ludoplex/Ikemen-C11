- [C11-ROADMAP.md](../../C11-ROADMAP.md) - Overall development roadmap and coding guidelines
- [COPILOT_C11_GUIDELINES.md](../../COPILOT_C11_GUIDELINES.md) - AI assistant guidelines

As the project develops, we will add:

- Memory management architecture

- Audio system design
- Network protocol specification
- Scripting system design
- Build and deployment guides
- Performance optimization notes
- Porting guides from Go to C11

## Contributing Documentation

When adding new subsystems or features:

1. Create a design document before implementing
2. Document architectural decisions (ADRs)
3. Keep documentation in sync with code
4. Use Doxygen comments in code for API documentation
